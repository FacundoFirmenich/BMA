# BayME–M_C Gate V source bundle

`bundles/bayme_mc_gate5_overlay.zip` is the frozen source overlay for Gate V.
It is applied on top of the Gate IV branch by the isolated GitHub Actions
workflow. The bundle contains the prospective field buffer, privacy-bound
tokenisation, stepped-wedge assignment, assignment→exposure→outcome lineage,
new JSON schemas, tests, round-zero official sensor calibration, freeze and
report builders.

The bundle SHA-256 and exact file inventory are recorded in
`bundles/bayme_mc_gate5_overlay_manifest.json`.

No policy execution authority, personal data, treatment assignment or M_C
exposure is included in this source bundle.

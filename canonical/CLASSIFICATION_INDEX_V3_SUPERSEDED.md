# Índice V3 supersedido

`CLASSIFICATION_INDEX_V3.csv` queda preservado como evidencia histórica, pero
no debe utilizarse como vista canónica vigente.

Fue supersedido porque:

- conservaba identificadores canónicos con prefijos de linajes históricos
  (`bma-`, `bayme-` y `eve-`);
- mezclaba en la superficie de identidad la clasificación nueva con la
  procedencia antigua;
- coexistía con un README de BUM que afirmaba erróneamente que no existían
  unidades adjudicadas, pese a que V3 ya registraba una.

La corrección vigente es `CLASSIFICATION_INDEX_V4.csv`. Los valores históricos
se conservan únicamente en `historical_source_lineage`.

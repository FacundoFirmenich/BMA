# Índice V4 supersedido

`CLASSIFICATION_INDEX_V4.csv` corrigió la mezcla nominal entre las familias
nuevas y los linajes históricos. Queda preservado, pero V5 lo supersede porque
la lectura completa del paquete multivertical recuperó unidades HBP monetarias,
inflacionarias y micro-meso-macro que V4 subsumía de forma demasiado gruesa.

La vista vigente es `CLASSIFICATION_INDEX_V5.csv`.
